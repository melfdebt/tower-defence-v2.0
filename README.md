# tower-defence-v2.0

**Tower Defence** — учебный проект игры в жанре Tower Defense, разработанный на **Godot Engine 4.7 (.NET)** с использованием **C#**.

## Описание проекта

Игрок управляет персонажем на игровой арене, перемещается по ней, уничтожает противников и размещает защитные башни. Необходимо выживать во время последовательных волн врагов и защищать игровое ядро.

Сложность постепенно увеличивается: с каждой новой волной количество противников возрастает.

## Основные механики

- **Управление персонажем:** перемещение по арене, поворот в сторону курсора и стрельба.
- **Строительство башен:** выбор типа башни и размещение её на доступной части арены.
- **Три типа башен:**
  - Basic Tower — наносит обычный урон.
  - Freeze Tower — использует замораживающие снаряды.
  - Explosion Tower — наносит урон по области.
- **Противники:**
  - Enemy — атакует с помощью снарядов.
  - Crawler — перемещается к ядру и наносит ему урон при контакте.
- **Система волн:** противники появляются в случайных точках арены. После уничтожения всех врагов начинается следующая волна.
- **Система здоровья:** игрок, противники и ядро имеют запас здоровья.
- **Интерфейс:** отображает номер текущей волны, количество оставшихся противников, здоровье игрока и ядра.
- **Условия поражения:** завершение игры при гибели игрока или уничтожении ядра.

## Управление

| Клавиша | Действие |
|---|---|
| W, A, S, D | Перемещение персонажа |
| ЛКМ | Стрельба |
| B | Включить режим строительства / подтвердить размещение башни |
| 1 | Выбрать Basic Tower |
| 2 | Выбрать Freeze Tower |
| 3 | Выбрать Explosion Tower |
| Esc | Отменить строительство |

В режиме строительства предварительный просмотр башни следует за персонажем. Цвет модели показывает, допустимо ли размещение в выбранной позиции.

## Архитектура проекта

Проект построен с использованием принципа композиции: игровые объекты получают необходимую функциональность через отдельные компоненты.

### Компоненты

- **HealthComponent** — хранение и изменение здоровья, обработка получения урона и смерти объекта.
- **MoveComponent** — управление перемещением и временной остановкой объектов.
- **ShootComponent** — создание и запуск снарядов.
- **DamagingComponent** — обнаружение столкновений и применение урона.
- **FreezeComponent** — специализированный компонент урона с эффектом замедления/заморозки.
- **ExplosionDamageComponent** — нанесение урона нескольким объектам в области взрыва.

### Менеджеры

- **GameManager** — отслеживание условий поражения и управление завершением игры.
- **WaveManager** — создание противников, управление волнами и подсчёт оставшихся врагов.
- **BuildingManager** — выбор, предварительный просмотр и размещение башен.
- **HUD** — обновление отображаемой игровой информации.
